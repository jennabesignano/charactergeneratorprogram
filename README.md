This program allows you to add character traits to a database based on a category. It then allows you to generate character lists based on randomly selected traits from each category and two random number traits (Strength and Magical Ability). It runs a main menu and an add traits menu. The user has the option to add new traits, print those traits to a database, generate lists of characters based on the added traits, print the generated lists of characters, and quit the program. This program handles invalid user input and re-prompts the user until they enter a valid integer. It does not allow users to add the same traits over and over again.
